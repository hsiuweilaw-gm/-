洗錢防制客戶風險評估系統 — Windows 試用包
============================================================

【這包是做什麼的】

給資訊人員或評估者在一台 Windows 電腦上把系統跑起來看。
不是正式部署方式，也不是給業務員安裝的東西——業務員只要用
瀏覽器連公司網址，不必安裝任何軟體。


【使用步驟】

1. 點兩下「安裝.bat」，等它跑完（第一次約 1 到 3 分鐘）
2. 點兩下「啟動.bat」，瀏覽器會自動開啟
3. 用示範帳號登入，密碼皆為 demo-password-1234

     agent01   業務員（看不到分數與風險等級）
     sup_tc    台中通訊處經理（agent01 的主管）
     aml01     洗錢防制專責
     audit01   內部稽核
     admin     系統管理者

4. 要停止系統：在黑色視窗按 Ctrl + C，或直接關掉該視窗


【下載後如果 Windows 擋下來】

從網路下載的檔案會被標記。解壓縮「之前」先處理：
  對 ZIP 檔按右鍵 → 內容 → 勾選最下方的「解除封鎖」→ 確定

執行 .bat 時若出現「Windows 已保護您的電腦」：
  點「其他資訊」→「仍要執行」


【需要 Python 3.11、3.12 或 3.13】

沒有的話，安裝.bat 會告訴您怎麼裝。

請注意：最新的 3.14 不能用。系統的套件版本是鎖定的（法遵系統
必須可重現），這些版本官方只編譯到 3.13。到 python.org 請找
3.13.x，不要點首頁最上方那顆大按鈕。

安裝 Python 時務必勾選「Add python.exe to PATH」。


【資料放在哪裡】

全部在這個資料夾內：
  dev.db    資料庫（示範資料）
  .env      設定與加密金鑰
  .venv     套件

不想要了就整個資料夾刪掉，Windows 完全恢復原狀，不留殘留。


【重要提醒】

此組態使用 SQLite 單檔資料庫與測試用金鑰，僅供試用與教育訓練，
不得用於正式環境。正式部署走 Docker + PostgreSQL + HTTPS，
另見 README.md。
