# tw-pii-masker：台灣個資檔案自動遮罩工具

自動偵測並遮罩 Word、Excel、PDF 檔案中的台灣個人資料（去識別化），
協助符合《個人資料保護法》的資料利用需求。

**完全在地端電腦執行，不連網、不上傳任何資料。** 安裝完成後即可離線使用。

## 功能特色

- **支援格式**：Word（.docx）、Excel（.xlsx / .xlsm，保留巨集）、PDF、純文字（.txt / .csv）
- **三層偵測機制**，大幅降低誤判：
  1. 正規表示式（格式比對）
  2. 檢查碼驗證——身分證字號、居留證號、統一編號、信用卡號都會驗算檢查碼，隨機數字不會誤遮
  3. 前後文關鍵字——護照號碼、銀行帳號、出生日期等易誤判類型，須出現相關關鍵字才觸發
- **表單／表格感知**：Word 表格與 Excel 儲存格會參考「左側儲存格」「欄位表頭」判斷，
  「姓名」欄底下的「王小明」、左欄「被保險人」右欄「李大華」這類排版都能正確遮罩
- **PDF 真實遮蔽（redaction）**：底層文字從 PDF 內容流中移除，
  無法以複製貼上或搜尋還原，不是只畫色塊蓋住
- **中繼資料清理**：預設一併清除文件屬性中的作者、最後修改者（常被忽略的個資外洩點）
- **原始檔不動**：輸出為 `原檔名_masked.副檔名` 新檔案
- **遮罩報告**：主控台摘要 + 可選 JSON 報告，預設不記錄原始個資內容

## 可偵測的個資類型

| 類型 | 機器名稱 | 偵測方式 | 部分遮罩範例 |
|---|---|---|---|
| 身分證字號 | `national_id` | 格式 + 檢查碼 | `A12****789` |
| 居留證號（新/舊式） | `arc_id` | 格式 + 檢查碼 | `A80****014` |
| 姓名 | `name` / `name_honorific` / `name_bare` | 欄位標籤／稱謂／表格提示（表格欄不要求姓氏庫） | `王○○` |
| 識別號碼（證照/考試/員編/帳號等欄） | `id_bare` | 表格欄位標題觸發 | `B1******33` |
| 電話（不規則格式） | `phone_bare` | 電話欄位標題觸發（無區碼、多值等） | `29****62` |
| 備註內號碼 | `note_digits` | 備註／注意事項欄的長數字保守全遮 | `00**-*****...` |
| 保單號碼／受理號碼 | `policy_no` | 「保單／受理」關鍵字觸發。**預設不遮**（保留供業務辨識），需要時加 `--mask-policy-no` | `11*****LN***23` |
| 出生日期 | `birthdate` | 民國/西元日期 + 出生關鍵字 | `民國**年*月**日` |
| 行動電話 | `mobile` | 09xx / +8869xx 格式 | `0912-***-678` |
| 市內電話 | `landline` | 區碼格式 | `(02)****-**56` |
| 電子郵件 | `email` | 格式 | `hs***@example.com` |
| 地址 | `address` / `address_ctx` / `address_bare` | 縣市（含改制前舊縣名）～樓層結構；未寫縣市者由「地址」標籤或表格提示觸發 | `台北市大安區***`（保留至鄉鎮市區） |
| 健保卡號 | `nhi_card` | 0000 開頭 12 碼 | `0000****--78` |
| 護照號碼 | `passport` | 8–9 碼 + 「護照」關鍵字 | `******123` |
| 統一編號 | `ubn` | 檢查碼 + 「統編」關鍵字 | `04****57` |
| 信用卡號 | `credit_card` | Luhn 檢查碼 | `****-****-****-1111` |
| 銀行帳號 | `bank_account` | 10–16 碼 + 「帳號」關鍵字 | `012****-**89` |
| 車牌號碼 | `plate` | 格式 + 「車牌」關鍵字 | `AB*-****` |

完整清單：`twmask --list-types`

## 安裝（一次性，之後可離線使用）

需求：Python 3.9 以上（Windows 可至 [python.org](https://www.python.org/downloads/) 下載，
安裝時勾選「Add Python to PATH」）。

```bash
# 下載或複製本專案後，在 pii-masker 資料夾執行：
pip install .
```

或不安裝套件、直接以原始碼執行：

```bash
pip install -r requirements.txt
python -m tw_pii_masker 檔案.docx
```

安裝的三個函式庫（python-docx、openpyxl、PyMuPDF）皆在本機處理檔案，
工具本身沒有任何網路存取程式碼；下載安裝完成後，離線環境即可使用。

## 使用方式

### 命令列

```bash
twmask 保單.docx                        # 產生 保單_masked.docx
twmask 名單.xlsx 理賠.pdf 備註.txt      # 一次處理多個檔案
twmask C:\文件\待遮罩 -r                # 遞迴處理整個資料夾
twmask 保單.docx -m label               # 改用 [身分證字號] 標籤取代
twmask 保單.docx -m full                # 全遮罩（整段 *）
twmask 保單.docx --dry-run              # 只偵測、列出結果，不輸出檔案
twmask 保單.docx --report result.json   # 另存 JSON 遮罩報告
twmask 名單.xlsx -t national_id,mobile  # 只遮身分證與手機
twmask 名單.xlsx -x ubn                 # 全部遮，但不遮統一編號
twmask 保單.docx --all-dates            # 所有完整日期一律遮罩
twmask 查核.xlsx --mask-policy-no       # 連保單號碼也一併遮罩（預設不遮）
twmask 查核.xlsx --mask-agent-names     # 連內部人員姓名也遮（預設不遮）
```

### 圖形介面（適合不熟指令的同仁）

```bash
twmask-gui
```

選檔案（或整個資料夾）→ 選遮罩模式 → 按「開始遮罩」即可。

### 遮罩模式

| 模式 | 說明 | 範例 |
|---|---|---|
| `partial`（預設） | 部分遮罩，保留頭尾供人工比對勾稽 | `A12****789`、`王○○` |
| `full` | 整段以 `*` 取代，長度不變 | `**********` |
| `label` | 以類型標籤取代，適合做範本或訓練資料 | `[身分證字號]` |

### 常用選項

| 選項 | 說明 |
|---|---|
| `-o 資料夾` | 指定輸出資料夾（預設與原檔同層） |
| `--suffix 後綴` | 自訂輸出檔名後綴（預設 `_masked`） |
| `--report 檔名.json` | 輸出 JSON 報告（類型、位置、遮罩後樣貌） |
| `--show-original` | JSON 報告中包含原文（**報告檔本身即含個資，請妥善保管**） |
| `--keep-metadata` | 保留文件作者等中繼資料（預設清除） |
| `--dry-run` | 只偵測不輸出，適合先確認偵測結果 |
| `--mask-policy-no` | 一併遮罩保單號碼／受理號碼（預設不遮，保留供業務辨識） |
| `--mask-agent-names` | 一併遮罩內部人員（業務員／帳號／經手人…）的姓名（預設不遮） |

## 與個資法的對應

《個人資料保護法》第 2 條第 1 款所列個資與本工具偵測類型的對應：

| 個資法列舉項目 | 本工具類型 |
|---|---|
| 姓名 | `name` / `name_honorific` / `name_bare` |
| 出生年月日 | `birthdate` |
| 國民身分證統一編號 | `national_id`（居留證：`arc_id`） |
| 護照號碼 | `passport` |
| 聯絡方式 | `mobile` / `landline` / `email` / `address` |
| 財務情況 | `credit_card` / `bank_account` |
| 病歷、醫療 | `nhi_card`（健保卡號）；病歷文字內容需人工判讀 |
| 其他得以直接或間接識別之資料 | `plate` / `ubn` 等 |

## 一致性遮罩（v1.3.0 起）

自由文字中的姓名，往往只有部分出現處帶標籤：

```
要保人 林宥慈(F220755862)：手機 0920094377 與 帳號 林宥慈(F220755862) 之 手機 相同
```

若只遮「要保人」後那一次，後面仍留明文姓名，遮罩形同虛設。因此本工具採兩階段處理：

1. **學習**：先掃過整份文件，登記所有確認為姓名的字串
2. **遮罩**：除本文偵測外，另把已登記姓名的**所有**出現處一併遮罩

遮罩結果：`要保人 林○○(F22****862)：手機 0920***377 與 帳號 林○○(F22****862) 之 手機 相同`

登記表以**單一文件**為範圍，一次處理多檔時不會互相污染。

## 客戶姓名遮罩、內部人員姓名保留（v1.5.0 起）

查核案件等內部文件需保留業務員身分才能追查，因此姓名是否遮罩，
**依「該處的標籤」逐處判斷**：

| 標籤類別 | 處理 | 標籤 |
|---|---|---|
| **客戶端** | **遮罩** | 姓名、保戶、要保人、被保險人、主被保人、副被保人、受益人、客戶、申請人、當事人、收件人、受文者、立書人、立契約書人、聯絡人、負責人、代理人、法定代理人、受款人、借款人、保證人、病患、患者、員工、推介者、輔導者、繼承人、介紹人、招攬人、推薦人、主管 |
| **內部人員** | **保留** | 業務員、招攬業務員、原業務員、新業務員、業務人員、業務代表、服務人員、登錄業務員、所屬業務員、招攬人員、帳號、帳戶名稱、帳號名稱、使用者、登入帳號、經手人、經辦人、承辦人、處理者、送件人、建立者 |

```
原文：要保人 林宥慈(F220755862)：手機 0920094377 與 帳號 林宥慈(F220755862) 相同
遮罩：要保人 林○○(F22****862)：手機 0920***377 與 帳號 林宥慈(F22****862) 相同
             ↑ 要保人 → 遮罩                      ↑ 帳號 → 保留
```

同一人可兼具兩種身分（既是要保人又持有業務員帳號），此時**在客戶標籤處遮、
在內部人員標籤處保留**——決定身分的是該處的標籤，不是這個人。

判斷細節：

- **只看姓名前方的文字**。「保戶 陳美玲 … 與 業務員/營業處所 相同」中的陳美玲
  身分是保戶，後方的「業務員」不影響判斷
- **無標籤處**：看該姓名在本文件是否曾以客戶身分出現過——曾是客戶就遮，
  只當過內部人員（如另一欄的「經手人 葉珍玲」）就保留
- 表格情境另看欄位標題（如欄位名為「業務員姓名」）；但**僅採短標籤**，
  鄰格長篇自由文字中偶然出現的「業務員」不會放行整列客戶姓名
- 欄位標題同時含兩類（如「業務員姓名」）時，**內部人員優先**

**注意：身分證、電話、地址等其他個資不受影響，內部人員的這些欄位一樣會遮罩**，
只有「姓名」保留。需要連內部人員姓名一起遮時，加 `--mask-agent-names`
（GUI 有對應勾選框）。

## 重要限制與注意事項（請務必閱讀）

1. **本工具是輔助，不是法律保證。** 自動偵測無法達到 100% 召回率，
   遮罩後的檔案**建議務必人工複核**再行利用或提供第三方。
   依法務部及金管會相關函釋，資料經遮罩後若仍可與其他資料組合間接識別特定個人，
   仍屬個人資料；是否構成「去識別化／匿名化」應依實際利用情境個案判斷。
2. **掃描影像 PDF**（無文字層）無法自動遮罩，工具會在報告中警告該頁，需先 OCR 或人工處理。
3. **姓名偵測**採「欄位標籤＋姓氏庫＋稱謂」啟發式，而非完整命名實體辨識：
   內文中沒有任何標記的姓名（例如敘述句中間的人名）可能漏偵，請以 `--dry-run` 搭配人工檢查。
4. **舊格式** .doc / .xls 不支援，請先以 Office 另存為 .docx / .xlsx。
5. Word 文字方塊、SmartArt、Excel 圖表與註解內的文字無法處理。
6. Excel 中**以數值形態儲存**的電話（如 912345678，開頭的 0 遺失）：
   欄位標題含「電話／手機／傳真」等字樣時會自動補回 0 並遮罩；
   其餘數值型號碼仍建議先將該欄設為文字格式。
7. 產出的 `--show-original` 報告與原始檔案本身仍含個資，請依貴公司個資檔案安全維護計畫管理。

## 開發與測試

```bash
pip install -e ".[dev]"
python -m pytest tests/       # 79 項測試：檢查碼、偵測、遮罩、一致性、身分分類、端對端
python samples/make_samples.py  # 產生示範檔案（虛構個資）試跑
```

## 專案結構

```
pii-masker/
├── tw_pii_masker/
│   ├── detectors.py      # 個資偵測（正規表示式＋檢查碼＋前後文）
│   ├── masking.py        # 遮罩策略（partial / full / label）
│   ├── engine.py         # 遮罩引擎
│   ├── report.py         # 報告（主控台＋JSON）
│   ├── cli.py            # 命令列介面（twmask）
│   ├── gui.py            # 圖形介面（twmask-gui，tkinter）
│   └── handlers/         # docx / xlsx / pdf / txt 各格式處理器
├── tests/                # pytest 測試
└── samples/              # 示範檔案產生器（虛構個資）
```
