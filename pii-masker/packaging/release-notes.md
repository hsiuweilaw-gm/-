## 台灣個資檔案自動遮罩工具 — Windows 免安裝執行檔

**不需要安裝 Python、不需要安裝任何東西**，下載後雙擊即可使用。
所有檔案處理都在你自己的電腦上完成，完全不連網、不上傳任何資料。

### 下載哪一個？

| 檔案 | 用途 |
|---|---|
| **TWPIIMasker-GUI.exe** | 圖形介面版（推薦）：雙擊開啟 → 選檔案 → 按「開始遮罩」 |
| twmask.exe | 命令列版：把 Word/Excel/PDF 檔案**直接拖曳到這個 exe 圖示上**即可遮罩；進階者可在命令列使用 |

### 使用方式（GUI 版）

1. 下載 `TWPIIMasker-GUI.exe`（第一次開啟時若出現藍色「Windows 已保護您的電腦」視窗，
   點「**其他資訊**」→「**仍要執行**」；這是 Windows 對所有未購買憑證簽章軟體的預設提示）
2. 按「選擇檔案」或「選擇資料夾」
3. 選擇遮罩模式（預設「部分遮罩」即可）
4. 按「開始遮罩」→ 遮罩後的新檔案出現在原檔案旁（檔名加 `_masked`），原始檔不會被更動

### 支援格式與偵測項目

- 格式：Word（.docx）、Excel（.xlsx/.xlsm）、PDF、純文字（.txt/.csv）
- 個資：身分證字號、居留證號、姓名、出生日期、行動／市內電話、Email、地址、
  健保卡號、護照號碼、統一編號、信用卡號、銀行帳號、車牌號碼（共 16 類，
  身分證／統編／信用卡皆有檢查碼驗證，降低誤遮）
- PDF 為真實遮蔽（redaction），底層文字自檔案中移除、無法還原
- 自由文字中的姓名採**全文件一致遮罩**：只要在文件任一處確認為姓名，所有出現處都會遮罩（不論該處有無「要保人」這類標籤）
- 保單號碼／受理號碼**預設保留**不遮，供業務辨識；需要時可在選項中勾選一併遮罩
- 姓名是否遮罩依**該處的標籤**判斷：客戶端（保戶、要保人、被保險人、受益人…）一律遮罩；內部人員（業務員、帳號、經手人、經辦人、處理者…）保留。同一人兼具兩種身分時，在客戶標籤處遮、在內部人員標籤處保留。內部人員的身分證、電話、地址等仍照遮，只保留姓名；需要連姓名一起遮時可在選項中勾選

### 提醒

- 自動偵測無法保證 100% 找到所有個資，重要文件對外提供前請人工複核
- 掃描影像型 PDF（無文字層）無法自動遮罩，工具會警告提醒
- 舊格式 .doc / .xls 請先另存為 .docx / .xlsx
