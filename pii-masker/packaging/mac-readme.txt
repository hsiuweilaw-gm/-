 台灣個資檔案自動遮罩工具（macOS 版）
══════════════════════════════════════════════════

本工具自動偵測並遮罩 Word（.docx）、Excel（.xlsx）、PDF、
純文字（.txt/.csv）檔案中的台灣個資。

★ 所有檔案處理都在你自己的電腦上完成，不連網、不上傳。
★ 免安裝，不需要安裝 Python 或任何東西。
★ 原始檔不會被修改，結果存成「原檔名_masked」新檔案。


──────────────────────────────────
 一、第一次使用（重要，只需做一次）
──────────────────────────────────

本工具沒有購買 Apple 的開發者簽章憑證，macOS 預設會擋下來，
顯示「無法打開，因為無法驗證開發者」。解除方式如下：

【方法 A：終端機一行指令（最快、最可靠）】

1. 開啟「終端機」（Terminal，可用 Spotlight 搜尋）
2. 輸入 xattr -cr 後面空一格
3. 把 TWPIIMasker.app 直接拖進終端機視窗（路徑會自動帶入）
4. 按 Enter

   完整指令會長得像這樣：
   xattr -cr /Users/你的帳號/Downloads/TWPIIMasker.app

5. 之後就能正常雙擊開啟了

【方法 B：系統設定】

1. 直接雙擊 TWPIIMasker.app，出現警告後按「完成」
2. 開啟「系統設定」→「隱私權與安全性」
3. 往下捲，會看到「已阻擋 TWPIIMasker」，按「仍要打開」
4. 再次雙擊即可

※ 這兩種方式都只需做一次。


──────────────────────────────────
 二、使用方式
──────────────────────────────────

【圖形介面】

雙擊 TWPIIMasker.app
  → 按「選擇檔案」或「選擇資料夾」
  → 選擇遮罩模式（預設「部分遮罩」即可）
  → 按「開始遮罩」
  → 遮罩後的新檔案會出現在原檔案旁邊（檔名加 _masked）

【命令列】

同一個資料夾裡的 twmask 是命令列版本。在終端機中：

    ./twmask 保單.docx                  處理單一檔案
    ./twmask 資料夾路徑 -r              整個資料夾（含子資料夾）
    ./twmask 保單.docx --dry-run        只偵測、先看結果不輸出
    ./twmask --help                     完整選項說明

若出現「Permission denied」，先執行：chmod +x twmask


──────────────────────────────────
 三、選哪一個檔案下載
──────────────────────────────────

  TWPIIMasker-mac-AppleSilicon.zip  → M1／M2／M3／M4 等晶片的 Mac
  TWPIIMasker-mac-Intel.zip         → 2020 年以前的 Intel 處理器 Mac

不確定的話：點左上角蘋果圖示 →「關於這台 Mac」，
看「晶片」欄位寫 Apple M 開頭就選 AppleSilicon，
寫 Intel 就選 Intel。


──────────────────────────────────
 四、重要提醒
──────────────────────────────────

1. 本工具為去識別化「輔助」工具，自動偵測無法保證找到所有個資。
   重要文件對外提供前，請務必人工複核一次。
2. 「掃描影像」型 PDF（整頁是圖片、無文字層）無法自動遮罩，
   工具會警告提醒，需先 OCR 或人工處理。
3. 舊格式 .doc / .xls 不支援，請先另存成 .docx / .xlsx。
4. iPhone／iPad（iOS）無法執行本工具——iOS 不允許這類直接讀寫
   本機檔案的應用程式，請在 Mac 或 Windows 電腦上使用。
